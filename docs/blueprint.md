# **App Name**: Munival

## Core Features:

- Bilingual Translation Engine: Switch seamlessly between English and Spanish via a dedicated UI toggle powered by localized data structures.
- Fiscal Input Center: Controlled input fields for gross income, applicable tax rates, and minimum taxable bases.
- Comparative Analytics Dashboard: Interactive bar charts that visualize tax breakdowns and compare current inputs against standard thresholds.
- Scenario Forecasting Tool: AI-powered tool to suggest optimization strategies and identify fiscal anomalies based on your historical tax data patterns.
- Quick Report Export: Generate and download a summarized PDF or CSV of your calculated municipal tax scenarios.

## Style Guidelines:

- Primary Color: Vibrant Emerald (#10B981) for clarity and visibility. Dark scheme primary (#34D399) used for high-contrast accessibility.
- Backgrounds: Clean slate white (#FFFFFF) for light mode and a deep navy charcoal (#0F172A) for a professional dashboard feel in dark mode.
- Headline and body font: 'Inter' for a machined, objective look. Pair with 'Source Code Pro' for displaying tabular numerical tax data and rates.
- Information-dense grid layout with a collapsible sidebar for inputs to prioritize chart visibility on mobile and desktop.
- Smooth, gradual transitions between chart data points to provide immediate feedback on slider or input changes.
- Monoline, minimalist icons represent fiscal documents and linguistic settings for a sleek digital-agency aesthetic.
